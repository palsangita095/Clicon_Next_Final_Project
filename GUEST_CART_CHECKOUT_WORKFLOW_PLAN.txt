GUEST CART/CHECKOUT WORKFLOW - IMPLEMENTATION PLAN
===================================================

OVERVIEW
--------
Implement Amazon-like guest shopping experience where non-logged-in users can:
- Add to cart/wishlist/compare (stored in localStorage)
- Proceed to checkout but must login to place order
- Auto-sync localStorage data to Supabase after login/register
- Auto-fill billing from account settings (read-only on checkout)

---

CURRENT STATE ANALYSIS
----------------------

Existing Stores:
1. useStorefront (src/store/useStorefront.ts) - Cart, Wishlist, Compare with Supabase sync
   - Already has rehydrate() that loads from Supabase for logged-in users
   - Already has enqueueDbWrite() for async DB persistence
   - Products/CartItem types defined inline

2. useAuthStore (src/store/useAuthStore.ts) - Auth state, login/register/logout
   - Calls useStorefront.rehydrate() on successful login
   - Sets cookies for token/role/user

3. Checkout page exists at src/app/(public)/checkout/

4. Account settings at src/app/(public)/account/settings/

### 8. CHECKOUT FLOW LOGIC

**Guest User Flow:**
1. Browse products → Add to cart/wishlist/compare → Saved to localStorage
2. Go to /checkout → See read-only billing form (empty or from localStorage if previously logged in)
3. Select payment method → See "Sign in required" banner
4. Click "Place Order" → Auth modal opens
5. Login/Register → Modal closes → syncGuestToSupabase() runs
6. Checkout page re-renders with user data → Billing auto-filled from profile
7. If profile incomplete → "Complete Account Details" modal → Redirect to settings
8. After profile complete → Return to checkout → Place Order works

**Logged-in User Flow:**
1. Browse → Add to cart → Saved to Supabase (existing)
2. Go to /checkout → Billing pre-filled from profile
3. Select payment → Place Order → Creates order in Supabase

### 13. EDGE CASES

- **localStorage full** → Catch quota exceeded, show warning
- **Sync fails** → Retry logic, keep guest data, show toast
- **Multiple tabs** → Storage event listener to sync across tabs
- **Guest + logged in simultaneously** → Not possible (single browser)
- **Cart quantity exceeds stock** → Validate on sync, adjust to max stock
- **Product deleted while in guest cart** → Filter out on sync, notify user
